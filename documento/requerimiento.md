# CONTROL RED MÉDICA

## RF-01 — Autenticación de Usuarios

### Descripción
El sistema debe permitir a los Administradores y Doctores iniciar sesión mediante correo y contraseña.

### Flujo normal
1. El usuario accede al login.
2. Ingresa correo y contraseña.
3. El sistema valida credenciales.
4. El sistema concede acceso.

### Excepciones
- Credenciales incorrectas.
- Cuenta desactivada.

### Prioridad
**Alta**
